# 工作流模板：修 bug / 重构

> 面向 bug 修复、重构、技术债、行为不变。强调先复现定位，再改，再回归。

## 适用场景
- 线上/测试暴露的 bug 修复
- 无功能变更的重构、消警告、拆大文件
- 技术债清理

## 规模
- 1 架构师 + 1 开发 + 1 测试 + 1 质量（串行为主，bug 常需连续复现）

## 阶段序列
| Phase | 角色 | 要点 |
|-------|------|------|
| 1 | 开发工程师 | 复现 + 定位根因 |
| 2 | 架构师 | 修复/重构方案 |
| 3 | 开发工程师 | 修复 / 重构（**保持行为不变**） |
| 4 | 测试工程师 | 回归测试 |
| 5 | 质量工程师 | 独立验收 |
| 6 | 主agent | 报告 + 知识沉淀 |

## 验收维度
- 行为不变：重构前后对外行为一致
- 回归：原有用例全部通过
- 根因修复而非表面绕过

## 输出
- 根因说明
- 修复/重构改动位置
- 回归结果
- 是否引入新风险
