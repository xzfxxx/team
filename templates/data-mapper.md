# 工作流模板：数据 / HANA + MyBatis 生成

> 面向数据库与数据访问层的模板。涉及表结构、SQL、MyBatis 生成器、映射、分页时选它。**默认只读，严禁改表**。

## 适用场景
- 依据表结构生成 Entity / Mapper 接口 / Mapper XML
- 编写或审核 SQL、分页、连表、字段映射
- HANA 特性 / 数据字典查询 / N+1 排查

## 规模
- 1 架构师（表分析）+ 1 数据库 + 1 开发 + 1 质量（可并行，但 DB 只读串行）

## 阶段序列
| Phase | 角色 | 要点 |
|-------|------|------|
| 1 | 数据库工程师 | 读表结构 / 元数据（只读） |
| 2 | 架构师 | 数据访问层设计 + 依赖 |
| 3 | 开发工程师 + 数据库工程师 | 生成 Entity/Mapper/XML + SQL |
| 4 | 质量工程师 | 11 维（重点 SQL 语法/映射/N+1） |
| 5 | 测试工程师 | SQL/映射边界测试 |
| 6 | 主agent | 报告 + 文档工程师 |

## 验收维度
质量工程师 11 维，**额外强化**：SQL 只读校验、LIMIT 强制、MyBatis 映射一致性。

## 输出
- 表结构分析
- 生成的 Entity/Mapper/XML 清单
- SQL 与映射一致性结论
- 性能风险点 + 优化建议
