# 工作流模板：纯查询 / 分析 / 调研

> 只查不改、调研、分析、出结论。轻量，不一定开团队。

## 适用场景
- 回答数据/业务问题、查表、跑只读 SQL
- 技术调研、可行性分析、方案对比
- 出结论/报告，不改代码

## 规模
- 1（主 agent 单人）或 1 架构师 + 1 数据库（数据相关）

## 阶段序列
| Phase | 角色 | 要点 |
|-------|------|------|
| 1 | 架构师 | 拆解调研问题、定方案 |
| 2 | 数据库工程师 | 查数 / 只读 SQL |
| 3 | 主agent | 结论 + 知识沉淀 |

## 验收维度
- 结论有依据（来源/数据可溯）
- 边界情况说明
- 无代码改动（只读）

## 输出
- 结论（含依据）
- 关键数据/SQL
- 后续建议

## 说明
无需完整团队；若需交叉验证可补一个独立质量 agent 复核结论。
